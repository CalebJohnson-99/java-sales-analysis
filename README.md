# java-sales-analysis
## Program Description
This program finds the most profitable consecutive period of sales over a year. The program uses two parallel arrays one for months and the other for the sales change for the corresponding month in millions. using a nested loop the program evaluates all possible combinations and out puts the largest value.

## Compiling
1. Open SalesAnalysis.java folder in IntelliJ IDEA
2. Edit the salesChange array as needed.
3. click the green play button on the left side of the screen.

## Output
When the program is executed it will output the start month, end month, and total sales change for the best period. 
example
---Sales Analysis---
Start Month: Feb
End Month:   Feb
Total Sales Change: -5.0 million

## Known Issues
Since the dataset is hard-coded into program it has to be reran each time a change is made to the salesChange array.
